# MILES CLUB — 내 핸드폰 번호 가격 알아보기

**데모 → https://milesclub-tmi.github.io/milesclub-number-value/**

휴대폰 뒤 8자리의 숫자 패턴을 분석해 엔터테인먼트용 예상 가치를 매기고 공유를 유도하는 미니앱입니다.
빌드 도구와 npm 의존성이 없습니다. 정적 파일을 그대로 서빙하면 동작합니다.
외부 요청은 한글 서체(jsDelivr)와 자산 시세 3곳(업비트·open.er-api·CoinGecko)뿐입니다. 전부 실패해도
시스템 서체와 기준 시세로 폴백되어 기능에는 영향이 없고, 사용자 데이터는 어디에도 실리지 않습니다. 첫 방문 기준 폰트 23개 청크 · 약 365KB를 내려받습니다 — 줄이려면 아래 "남은 것" 참고.

```bash
npm run dev        # http://localhost:4173
npm test           # node:test 57개 (엔진·마크업·분포 + 실제 Chrome 스모크)
npm run calibrate  # 점수 보정 테이블 재생성 (약 9분)
```

## 구조

| 경로 | 역할 |
| --- | --- |
| `src/number-value.js` | 점수 엔진. DOM·네트워크·난수를 쓰지 않는 순수 모듈 |
| `src/score-calibration.js` | **생성 파일.** 패턴 점수의 전수 분포(CDF) |
| `src/app.js` | DOM 바인딩, 화면 전이, 공유 이미지, 분석 이벤트 |
| `src/icons.js` | SVG 아이콘 32개. DOM과 Canvas가 공유하는 도형 정의 |
| `src/asset-prices.js` | 원화 → 달러·금·주식·비트코인 환산. 달러·금·BTC는 실시간 |
| `scripts/calibrate.mjs` | 보정 테이블 생성기 |
| `test/e2e.test.mjs` | 실제 Chrome을 띄워 조작하는 스모크 테스트 (의존성 없음) |
| `index.html` / `styles.css` | 단일 화면. `data-state`(input → analysis → result)로 전환 |

## 화면

`data-state`(input → analysis → result) 하나로 전환하는 단일 화면이고, 세 상태 모두 **스크롤 없이 한 화면**에
들어갑니다(430×932 기준 932px).

- 서체는 글리프 단위 폴백으로 2단 구성입니다. 숫자·영문은 `ui-rounded`(애플 기기에서 **SF Pro Rounded**),
  한글은 **나눔스퀘어라운드**입니다.
- 굵기는 **본문 700, 제목·금액·등급 800** 두 단계만 씁니다. 나눔스퀘어라운드가 300/400/700/800만
  제공하므로 `500`은 400으로, `600`은 700으로 매칭됩니다 — CSS에 없는 굵기를 적으면 의도와 다르게
  렌더되니 700/800으로만 적으세요.
- 결과가 **재미로 보는 것이며 실제 시장 가치가 아니라는 문구**를 입력 화면 하단과 결과 히어로 카드,
  공유 이미지 세 곳에 노출합니다. 접혀 있는 `자세히 보기` 안에만 두지 않습니다.
- 색은 무채색 기반에 브랜드 애시드 그린(`--accent`) 하나만 등급 배지에 씁니다. 능력치 바는 먹색입니다.
- 회색 계조는 **WCAG AA(4.5:1)를 넘도록** 잡혀 있습니다. `--ink-2` 8.67, `--ink-3` 5.01(흰 카드 기준)입니다.
  아이콘·구분선처럼 텍스트가 아닌 요소는 명암비 대상이 아니므로 `--icon-muted`를 따로 씁니다.
  **텍스트에 `--icon-muted`를 쓰지 마세요.**
- 등급별 연출이 3단계입니다. `GRADE_TIER`가 `base`(NORMAL·SILVER) / `shiny`(GOLD·PLATINUM, 반짝임 켜짐) /
  `rare`(DIAMOND·LEGEND, 히어로 카드가 먹색으로 뒤집히고 금액이 애시드 그린)로 나눕니다. 공유 이미지도
  같은 등급 연출을 따릅니다.
- 아이콘은 이모지 대신 직접 그린 SVG 28개(`src/icons.js`)를 씁니다. 도형을 원시 형태로 저장해
  **DOM(SVG)과 공유 이미지(Canvas Path2D)가 같은 정의를 공유**합니다 — 한쪽만 바뀌는 일이 없습니다.
  전부 `currentColor`라 어두운 히어로 카드에서 자동으로 반전됩니다.
- 아이콘 매핑(`GRADE_ICON` / `TYPE_ICON` / `PATTERN_ICON` / `STAT_ICON`)은 표현 레이어인 `app.js`에만
  둡니다. 점수 엔진은 UI를 모릅니다. 마크업에 `data-icon="이름"`을 붙이면 자동으로 채워집니다.
- 상세 근거와 고지 문구는 기본으로 접어 두고 `자세히 보기`(`<details>`)로 엽니다. 열면 +217px입니다.
- `자랑하기` / `다시하기`는 화면 하단에 고정합니다(`.actions`). `.result` 안에 있어서 입력·분석 화면에서는
  자동으로 사라집니다. 콘텐츠가 가리지 않도록 `ResizeObserver`가 바 높이를 `--actions-height`로 넣고
  `.result`가 그만큼 아래 여백을 잡습니다 — 공유 폴백이 열려 바가 커져도 따라갑니다.
- 금액은 카운트업, 능력치 바는 80ms 간격으로 차오르고, 분석 진행바는 분석 시간에 맞춰 채워집니다.
  `prefers-reduced-motion`이면 전부 즉시 최종 상태로 넘어갑니다.
- 금액 글자 크기는 자릿수에 반비례합니다(`--value-length`). 1,000원부터 90,000,000원까지 항상 한 줄입니다.

## 점수가 매겨지는 방식

3단계입니다.

**1. 패턴 점수 (0~100).** 7개 항목에 가중치를 두고 더합니다.

| 항목 | 배점 | 보는 것 |
| --- | --- | --- |
| 반복성 | 22 | 전체 반복, 4자리 동일, ABAB, 페어, 인접 더블·트리플 |
| 기억 용이성 | 18 | 큰 단위 규칙, 의미 숫자, 날짜 배열, 라운드 넘버 |
| 연속성 | 16 | 전체 연속·역순, 구간 연속, 3자리 이상 흐름, 등차 흐름 |
| 대칭성 | 14 | 전체 대칭, 구간 회문, 부분 대칭, 수미상관 |
| 동일 숫자 밀도 | 12 | 최다 등장 횟수, 서로 다른 숫자 개수 |
| 전체 패턴 완성도 | 10 | 8자리가 하나의 규칙으로 읽히는 정도 |
| 특수 희소성 | 8 | 무중복, 올짝수·올홀수, 의미 숫자 |

여기에 조합 보너스와 배수(최대 1.16)를 곱합니다.

**2. 순위 환산.** 패턴 점수만으로는 결과가 한쪽에 몰립니다. 그래서 `SCORE_CDF`로 패턴 점수를
전체 010 번호 1억 개 안에서의 순위(0~1)로 바꿉니다. 같은 패턴 점수를 받은 번호끼리는 모델상
구분이 불가능하므로, 그 점수 구간 **안에서만** 번호 해시로 순서를 매겨 균등하게 펼칩니다.
결과적으로 순위는 전체에 대해 정확히 균등 분포가 되고, `상위 X%`는 실제 순위를 뜻합니다.

**3. 등급과 금액.** 등급은 순위 구간으로 나눕니다. 목표 비율은 아래와 같고, 실측치(40만 건
무작위 표본)가 함께 적혀 있습니다.

| 등급 | 목표 | 실측 | 금액대 |
| --- | --- | --- | --- |
| NORMAL | 45% | 45.0% | 1,000 ~ 30,000원 |
| SILVER | 27% | 26.9% | 30,000 ~ 150,000원 |
| GOLD | 17% | 17.1% | 150,000 ~ 800,000원 |
| PLATINUM | 9% | 9.0% | 800,000 ~ 5,000,000원 |
| DIAMOND | 1.8% | 1.8% | 5,000,000 ~ 30,000,000원 |
| LEGEND | 0.2% | 0.21% | 30,000,000 ~ 90,000,000원 |

금액은 등급 구간 안에서 로그 보간합니다. 위치는 **패턴 점수 72% + 순위 28%**로 정합니다.
순위만 쓰면 상위 구간에서 희소성이 포화해 `010-1122-3344`와 `010-7777-7777`이 같은 금액이
되기 때문입니다. 이 불변식은 `test/distribution.test.mjs`가 지킵니다.

같은 번호는 언제나 같은 결과를 냅니다. 난수 대신 번호의 FNV-1a 해시를 씁니다.

3자리 의미 숫자(`486`·`119`·`112`)는 **4자리 블록의 앞이나 뒤에 붙어 있을 때만** 인정합니다.
블록 경계를 가로지르는 우연한 일치(`3721|1260` → "112")는 아무도 그렇게 읽지 않기 때문입니다.

화면에 나가는 문장은 전부 해요체입니다. 엔진이 만드는 문자열도 마찬가지이니 새 문구를 넣을 때 맞춰주세요.

## 자산 환산 시세

결과 화면 "이 돈이면" 섹션의 시세입니다. **화면을 막지 않습니다** — 스냅샷으로 먼저 그리고
도착하면 조용히 갈아끼웁니다. 전부 실패해도 스냅샷이 그대로 남아 사용자는 아무것도 눈치채지 못합니다.

| 자산 | 소스 | 비고 |
| --- | --- | --- |
| 달러 | open.er-api.com | USD→KRW |
| 금 | CoinGecko PAXG | 금 1트로이온스 추종 토큰 → 돈(3.75g) 환산. **국제 시세 기준** |
| 비트코인 | 업비트 | KRW 직접 |
| 삼성전자·엔비디아 | 없음 (스냅샷) | 네이버·야후·Stooq 전부 CORS 차단 |

브라우저에서 무료로 주식 시세를 받을 방법이 없습니다. AlphaVantage 무료 키는 CORS는 통과하지만
**하루 25회를 전체 방문자가 공유**해 실사용이 불가능합니다. 그래서 주식만 `REFERENCE_PRICES`의
스냅샷을 쓰고, 실시간과 섞일 때는 화면에 "주식은 YYYY.MM.DD 기준이에요"를 함께 노출합니다.
**스냅샷 값은 배포 전에 갱신하고 `asOf`도 같이 고치세요.**

응답은 sessionStorage에 10분 캐시합니다. 개별 소스는 4초 타임아웃이고 하나가 죽어도 나머지는 삽니다.

호스트 앱이 시세를 안다면 전역으로 넣어주세요. **이 경우 외부 요청을 아예 하지 않습니다.**

```html
<script>
  window.MILES_ASSET_PRICES = {
    asOf: "2026-08-12",
    assets: [{ key: "usd", label: "미국 달러", unit: "달러", icon: "dollar", krw: 1390 }]
  };
</script>
```

점수 엔진과 분리돼 있어 시세를 바꿔도 **재보정은 필요 없습니다.**

## 점수 엔진을 고쳤다면 반드시 재보정하세요

`SCORE_CDF`는 현재 채점 로직에 종속됩니다. 채점을 건드리면 분포가 어긋나고 등급 비율이 무너집니다.

```bash
npm run calibrate   # 1억 개 전수 계산, 워커 9개 기준 약 9분
```

재보정을 잊으면 `calibration table still matches the current scorer` 테스트가 실패합니다.

## 개인정보 처리

- 전화번호 원문은 서버로 전송하지 않고, URL·분석 이벤트에도 넣지 않습니다. 분석은 전부 브라우저 안에서 끝납니다.
- `track()`은 화이트리스트에 있는 6개 키(`score_bucket`, `grade`, `detected_pattern_types`,
  `estimated_value_bucket`, `entry_source`, `shared_entry`)만 통과시킵니다.
- 공유 URL은 `?from=share`와 **등급(`g`) 하나만** 싣습니다. 번호·금액은 절대 넣지 않습니다.
  유입자에게 "친구는 LEGEND 번호였어요" 맥락을 주기 위한 최소 정보이고, 알 수 없는 값은 무시합니다.
- 화면에는 `010-12••-5678`, 공유 이미지에는 `010-••••-••78`까지만 노출합니다.

이 약속은 `test/markup.test.mjs`가 코드 수준에서 검증합니다 — 공유 URL 파라미터 화이트리스트와
분석 이벤트 키 목록을 각각 고정해 두었습니다.

분석 이벤트는 11종입니다. 이탈 지점도 함께 잡습니다: `number_value_input_error`(번호 입력 실패),
`number_value_analyze_error`, `number_value_runtime_error`(실기기 예외).

## 호스트 앱 연동

요금제 성향 테스트 CTA는 실제 링크(`<a>`)입니다. 기본 동작은 그냥 이동이고,
호스트 앱이 웹뷰 안에서 직접 라우팅하려면 `miles_navigate`에 `preventDefault`를 걸면 됩니다.

```js
window.addEventListener("miles_navigate", (event) => {
  // event.detail === { target: "plan_type_test", url: "https://milesclub.co.kr/apps/plan-type-test?..." }
  event.preventDefault(); // 기본 이동을 막고 앱 내부 라우팅으로 처리
});
```

링크 대상은 `index.html`의 `href`에 있습니다(utm 파라미터 포함). 바꾸려면 거기만 고치면 됩니다.
분석 이벤트는 `miles_analytics` 커스텀 이벤트와 `window.dataLayer` 양쪽으로 나갑니다.

## 남은 것

- 실기기 검증은 아직 없습니다. E2E는 헤드리스 Chrome 에뮬레이션이라 iOS Safari의 `navigator.share`,
  홈 인디케이터, 키보드가 올라올 때의 레이아웃은 실제 폰으로 확인해야 합니다.
- 의미 숫자 사전(`MEANING_NUMBERS`)은 8개뿐입니다. 늘리면 재보정이 필요합니다.
- 폰트가 첫 방문에 365KB입니다. 카피가 전부 소스에 고정돼 있으니 실제 쓰이는 글자만 서브셋하면
  두 굵기 합쳐 30~50KB로 줄고 외부 CDN 의존도 사라집니다(사내 폐쇄망 대응). 대신 카피를 바꿀 때마다
  재생성이 필요하므로 `npm run subset-font` 같은 스크립트로 묶어야 합니다.
- 파비콘이 없어 `/favicon.ico` 404가 한 번 발생합니다. 호스트 앱에 임베드되면 무해하지만 단독
  배포 시에는 넣어주세요.
